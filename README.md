## Project Workflow

### 1. Data Loading

The raw dataset was imported into Python using Pandas and inspected to understand its structure, columns, data types, and overall quality.

### 2. Exploratory Data Analysis (EDA)

EDA was performed to identify patterns, trends, relationships, and potential issues within the dataset.

Key activities included:

* Understanding dataset dimensions
* Checking data types
* Analyzing numerical and categorical variables
* Identifying missing values
* Detecting duplicate records
* Studying distributions and trends
* Generating exploratory visualizations

### 3. Data Cleaning

The dataset was prepared for further analysis by:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing inconsistent values
* Removing or handling irrelevant data
* Preparing clean analytical columns

### 4. MySQL Analysis

The cleaned dataset was imported into **MySQL Server**.

SQL queries were then used to perform analytical tasks such as:

* Aggregations
* Filtering
* Sorting
* Grouping
* Calculating KPIs
* Identifying trends
* Comparing categories
* Extracting business insights

### 5. Power BI Dashboard

The cleaned/processed data was connected to Power BI to create an interactive dashboard.

The dashboard includes:

* KPI cards
* Charts and graphs
* Category-wise analysis
* Trend analysis
* Interactive slicers/filters
* Key performance indicators
* Business insights

### 6. Report

A detailed analytical report was prepared to document:

* Project objective
* Dataset overview
* Data cleaning process
* EDA findings
* SQL analysis
* Dashboard insights
* Key conclusions

### 7. Presentation

A professional presentation was created using **Gamma** to summarize the project, methodology, findings, dashboard, and key recommendations.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/your-repository-name.git
cd your-repository-name
```

### 2. Set Up Python Environment

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Run the Jupyter Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```text
notebooks/EDA_and_Data_Cleaning.ipynb
```

Run the notebook cells sequentially.

### 4. Set Up MySQL

* Install and start MySQL Server.
* Create a database.
* Import the cleaned dataset.
* Run the SQL queries available in:

```text
sql/analysis_queries.sql
```

### 5. Open the Power BI Dashboard

Open:

```text
powerbi/dashboard.pbix
```

Update the MySQL connection details if required and refresh the data.
